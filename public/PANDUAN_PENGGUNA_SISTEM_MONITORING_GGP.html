Dashboard Peta GIS & Filter Wilayah

Pemetaan sebaran 579 gereja di seluruh kepulauan Indonesia dengan citra satelit

Alur 2 Eksplorasi Peta & Filter Multi-Kriteria

Klik tombol "Buka Dashboard" atau menu "Dashboard" di navigasi atas. Peta interaktif akan menampilkan sebaran seluruh titik gereja GGP di atas citra satelit resolusi tinggi.

  • Pencarian Cepat: Ketik nama gereja pada kotak "Cari Nama Gereja..." di FilterBar.
  • Filter Mada & Wilayah: Pilih dropdown Daerah atau Wilayah untuk fokus ke provinsi/kabupaten tertentu.
  • Layer Control: Di sisi kiri, Anda dapat mengaktifkan/menonaktifkan layer Batas Mada, Batas Wilayah, dan Titik Gereja.
  • Pelacak Koordinat: Di pojok kanan bawah, koordinat Lat / Long kursor bergerak secara real-time.

3

Detail Gereja, Live GPS & Rute Tercepat

Membaca informasi lengkap gereja dan menggunakan sistem navigasi jalan raya OSRM

Alur 3 Membuka Drawer Informasi & Navigasi Turn-by-Turn

Ketika Anda mengklik salah satu pin gereja di peta:

  1. Drawer Detail Terbuka: Menampilkan nama gereja, foto bangunan, nama pendeta, alamat lengkap, dan nomor kontak WhatsApp.
  2. Hubungi WhatsApp: Klik nomor telepon/WA untuk langsung terhubung ke aplikasi WhatsApp pendeta/gembala sidang.
  3. Tombol "Lokasi Saya": Klik tombol 📍 di toolbar peta untuk mendeteksi posisi GPS perangkat Anda secara langsung.
  4. Tombol "🚗 Petunjuk Arah & Rute Tercepat": Klik tombol ini di drawer detail. Sistem akan otomatis menghitung rute berkendara tercepat dari lokasi Anda ke gereja target, menggambar garis rute biru di peta, dan menampilkan panduan belokan jalan (turn-by-turn guidance) dalam Bahasa Indonesia.
💡 Keunggulan Rute In-App: Panduan rute jalan ditampilkan 100% langsung di atas peta website tanpa perlu membuka aplikasi pihak ketiga. Tersedia juga tombol cadangan untuk membuka Google Maps bagi pengguna ponsel.

Login Administrator & Hak Akses

Gerbang keamanan akses portal manajemen data dengan HTTP-Only Cookie

Alur 4 Masuk ke Panel Admin (/admin)

Kunjungi URL http://191.101.190.174:3007/admin:

  • Masukkan Username: superadmin
  • Masukkan Password: password akun yang diberikan oleh administrator.
  • Klik tombol "Masuk ke Panel →".
  • Sesi login dilindungi token terenkripsi dalam HTTP-Only Session Cookie selama 7 hari penuh.

5

Manajemen Master Data Gereja & Ekspor

Pengelolaan 579 data gereja di PostgreSQL dan ekspor berkas GeoJSON / CSV

Alur 5 Tab Master Data: Tambah, Edit, Hapus, dan Ekspor

Setelah berhasil login, Anda akan langsung disambut oleh halaman Master Data:

  • Ringkasan KPI Admin: Menampilkan Total Gereja (579), Total Mada (20), Total Mawil (63), dan Baris Terfilter.
  • Pencarian & Filter Cepat: Cari gereja berdasarkan nama jemaat, nama pendeta, atau alamat.
  • Tombol "+ Tambah Gereja Baru": Membuka formulir untuk mendaftarkan gereja baru lengkap dengan koordinat spasial X dan Y.
  • Tombol Ekspor (GeoJSON & CSV):
    • Tombol hijau 📥 GeoJSON: Mengunduh data spasial untuk software SIG (QGIS/ArcGIS).
    • Tombol putih 📥 CSV: Mengunduh tabel spreadsheet siap buka di Microsoft Excel.
  • Kolom Aksi (Edit & Hapus): Klik ikon pensil untuk mengubah data, atau ikon tong sampah untuk menghapus data dari database.

Manajemen Akun Pengguna & Fitur Edit

Pengelolaan akun admin, pembagian peran hak akses, dan pembaruan kata sandi

Alur 6A Melihat Daftar Akun di Tab "Pengguna"

Klik tombol navigasi "👥 Pengguna" di bagian atas panel admin. Tabel daftar akun menampilkan nama pengguna, username, peran (Super Admin atau Administrator), tanggal dibuat, serta tombol aksi.

Tab Pengguna — Manajemen Akun Administrator Sistem
📸 Gambar 6: Daftar akun pengguna sistem dengan tombol Edit dan Hapus pada setiap baris akun.
Alur 6B Mengedit Profil Pengguna & Mengganti Password Akun

Untuk memperbarui data akun atau me-reset kata sandi pengguna:

  1. Pada baris akun yang ingin diubah, klik tombol berwarna biru "Edit".
  2. Modal interaktif "Edit Data Pengguna" akan muncul di layar.
  3. Ubah Nama Lengkap atau Username jika diperlukan.
  4. Password Baru: Masukkan password baru (minimal 8 karakter) jika ingin mengganti kata sandi. Jika tidak ingin mengubah password, biarkan kolom ini kosong.
  5. Peran / Role: Pilih apakah akun memiliki hak akses Administrator (hanya master data) atau Super Administrator (akses penuh termasuk kelola user).
  6. Klik tombol biru "Simpan Perubahan". Data akan langsung ter-update di database PostgreSQL!
